`network` prints the selected network's config from `radius-sdk` (chain id, CAIP-2 id, RPC, explorer, facilitator and faucet URLs, native currency, SBC address, decimals and EIP-712 domain), with `--rpc-url` / `--sbc` overrides applied, as text or `--json`. It reads no chain state.
