## What is Radius?

Radius is a high-throughput, low-cost, stablecoin-native payment engine for agentic commerce: agents buying resources or services on a user's behalf. `radius-sdk` adds payments to a TypeScript API or client, and its Ethereum-compatible interfaces let developers use familiar wallets, signing tools, and libraries.

- [Why Radius](/why-radius): high throughput, low costs, stablecoin-native payments, enterprise integration, and micropayments.
- [Try Radius](/try): create a testnet wallet, send SBC, and pay for an API request from your browser.
- [Architecture](/architecture): follow a payment from authorization to delivery, and see how the engine and its operating model work.
