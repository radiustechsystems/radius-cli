# Data providers [Sell data by the request]

Offer agents and applications paid access to a query, record, or result. Radius checks and completes the payment before you return the data.

## Example payment flow

A threat-intelligence API charges for one lookup. The agent sees the price, authorizes payment, and receives a structured result that it can use in its task.

## Plan your integration

- Choose what one payment buys, and distinguish fixed-price results from variable-size queries.
- State what happens when a query returns no data or an incomplete result.
- Define freshness, permitted use, and any limits on redistribution.
- Track settlement and delivery separately so a failed response has a recoverable outcome.

## Evaluate with Radius

Start with one fixed-price endpoint using [accept payments](/build/accept-payments). Use a separate buyer wallet and the [make payments journey](/build/make-payments) to exercise the complete exchange.
