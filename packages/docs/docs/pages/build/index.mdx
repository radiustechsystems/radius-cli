# Build on Radius [Accept payments, make payments, and set up your tools]

Start with the payment task you need. The setup guides cover wallets, testnet funds, and tooling. To see a payment before you write code, [try Radius in your browser](/try).

## Payments

- [Accept payments](/build/accept-payments): charge for API routes in Workers, Hono, or other HTTP frameworks with `radius-sdk`.
- [Make payments](/build/make-payments): pay x402 endpoints from an app or agent with `radius-sdk`, or from a terminal with `radius-cli`.
- [x402 payments](/build/x402): how a paid request works on Radius, for custom integrations.

## Tutorials

- [Sell a data lookup](/build/tutorials/sell-data): build a Worker that charges 0.001 SBC per request on testnet.
- [Buy a data lookup](/build/tutorials/buy-data): pay for it with a limit, confirm the settlement, and give it to an agent with a budget.
